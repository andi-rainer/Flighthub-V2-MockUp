# FlightHub V2: Projektdokumentation

Zweck: Wer weiterarbeitet (Mensch, Agent, Claude), findet hier, was V1 kann, was für V2 beschlossen ist, was der Klickdummy schon zeigt und was noch zu klären ist. Nichts wird angenommen: Jede Aussage trägt eine Marke.

## Marken

| Marke | Bedeutung | Vorgabe? |
|---|---|---|
| `[V1]` | Fakt über V1 | Fakt |
| `[Beschlossen]` | Entschieden, gilt für V2 | ja |
| `[Richtung]` | Richtung angenommen, Details nicht ausgearbeitet | Richtung ja, Details nein |
| `[Entwurf]` | Lösung von Claude im Klickdummy, nicht bestätigt | nein |
| `[Vorschlag]` | Idee oder Vermutung, nicht entschieden | nein |
| `[Offen]` | Frage oder Ablauf, der noch zu klären ist | nein |
| `[Recherche]` | Fund aus dem Internet, ungeprüft | nein |

Bei Beschlossenem zeigt ein Symbol den Stand im Klickdummy: ✔ gezeigt, ○ noch nicht gezeigt (Umsetzung nötig).

## Pflege

- Neue Entscheidung → in 02 eintragen, aus 04 entfernen, bei Auswirkung auf den Dummy 03 anpassen.
- Neue Idee oder Frage → nur in 04, mit Marke.
